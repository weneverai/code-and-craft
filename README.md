# Code & Craft

Code & Craft is a generative art studio building playful systems that turn cultural patterns, sound, place, and material traditions into digital tools, physical editions, workshops, and installations.

## Structure

- `/` — Code & Craft umbrella homepage
- `/travel-tiles/` — Travel Tiles museum, studio, play, and shop system
- `/vibeweaving/` — bridge to Vibeweaving, the first research instrument from Code & Craft

## Deployment

Static HTML site. Deploy with Vercel or Cloudflare Pages.
