How it works

From signal to object.

The work keeps a relationship to where it came from, how it was generated, and what it becomes.

01 · Source

Begin somewhere.

A place, sound, archive, tradition, textile structure, or field note becomes the starting point.

02 · System

Build a grammar.

Code turns the source into rules for pattern, color, rhythm, form, motion, or material behavior.

03 · Object

Make it tangible.

The system becomes a tile, textile, print, light work, workshop, installation, or edition.
